# Getting Started [Get started in just a few lines of code.]

## Overview

`@aave-dao/toolbox` is a utility package that includes a wide range of features useful for everyday work in web3.

`@aave-dao/cli` as the name suggests is a cli package that can be executed as standalone via `npx @aave-dao/cli`

## Installation

:::code-group

```bash [npm]
npm i @aave-dao/toolbox
```

```bash [pnpm]
pnpm i @aave-dao/toolbox
```

```bash [bun]
bun i @aave-dao/toolbox
```

:::
